# TROLIST – דף נחיתה (שתי אופציות)

- `option-a/` – אופציה א׳: הירו, סקשן העומס עם המזוודה, ורצף התג המפורק.
- `option-b/` – אופציה ב׳: הירו חדש וסקשן העומס.

הפעלה מקומית (מתוך התיקייה של האופציה):

    python3 -m http.server 8000

ואז http://localhost:8000

הפונטים (Tel Aviv Brutalist, Ping HL) נמצאים בתיקיית `fonts/` של כל אופציה.
